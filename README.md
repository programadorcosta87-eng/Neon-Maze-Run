# Neon Maze Run

Minigame original de labirinto com estética arcade retrô, criado em HTML, CSS e JavaScript puro.

## Recursos
- Controles por teclado, botões touch e gestos de deslizar
- Pontuação, vidas, fases e pausa
- Inimigos com comportamentos diferentes
- Itens especiais que deixam inimigos vulneráveis temporariamente
- Fases progressivamente mais difíceis
- Contagem regressiva
- Sons gerados com Web Audio API
- Recorde salvo no `localStorage`
- Layout responsivo para Android e iPhone

## Como executar
Abra `index.html` diretamente no navegador ou publique os arquivos em qualquer hospedagem estática.
