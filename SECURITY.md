# Política de Segurança

## Dados sensíveis
Este projeto não deve conter tokens, chaves de API, senhas, certificados privados ou arquivos `.env` com valores reais.

Se algum segredo for enviado ao repositório por engano:
1. Revogue ou rotacione o segredo imediatamente.
2. Remova o valor do código e da configuração pública.
3. Atualize os serviços que dependiam da credencial.
4. Revise o histórico e os logs de acesso quando necessário.

## Relatar vulnerabilidades
Não publique credenciais ou detalhes sensíveis em issues públicas. Use um canal privado do mantenedor para reportes de segurança.
